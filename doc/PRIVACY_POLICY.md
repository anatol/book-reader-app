# Privacy Policy for Booklight

Last updated: 2026-05-18

Booklight is designed to read your local PDF and EPUB files with minimal data handling.

## Data Collection

Booklight does not collect personal data for analytics, advertising, or tracking.

- No analytics SDK
- No ad SDK
- No account system
- No background telemetry

## Network Use

Booklight does not make network calls as part of normal operation.

If you choose to sync app data between your own devices, that is done through third-party sync tools you configure separately (for example, Syncthing or cloud file storage providers). Those tools operate under their own privacy policies.

## Local Storage

Booklight stores data on your device, including:

- Library/source folder references
- Book metadata needed for indexing and display
- Reading position/progress
- Cached artwork and file hashes for performance

This data is used only to provide app functionality.

## File Access

Booklight accesses files and folders only after you explicitly grant access using system file pickers.

## Third Parties

Booklight does not sell your data and does not share personal data with third parties.

## Children’s Privacy

Booklight does not knowingly collect personal information from children.

If this policy changes, the “Last updated” date will be revised.
